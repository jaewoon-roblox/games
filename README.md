로블록스 게임 전용 개발 저장소.

## 코드 복사 검증

- 원본: https://github.com/hans1177/jaewoon-games/tree/980d73239331ad71b616d3344ead9e3165c10421/roblox-games
- `roblox-games/` 원본 413개 파일을 같은 경로에 보존 복사함.
- 모든 파일의 Git blob SHA와 파일 모드가 원본과 일치함.
- 원본 하위 트리: `fc2c71cb74ec82747639c82731f53d3fbd7966e2`.
- 게임 규칙·저장·전투·밸런스 코드는 수정하지 않음.
- 이번 반영은 코드 스냅샷 복사이며 원본 커밋 이력의 이전은 아님.

## 아직 완료하지 않은 범위

- 공용 자산 및 라이선스 원장 연결.
- 기존 바이브 자동화·실행 상태 브랜치의 플랫폼별 분리.
- 조직 실행기와 게시 비밀값 연결.
- 새 저장소 단독 Rojo 빌드·모바일·저장/재접속·게시 검증.
- 기존 저장소의 로블록스 작업 중단 및 웹 전용 전환.

검증 전까지 기존 개발·게시 경로를 유지함. 웹 게임 개발은 기존 저장소에 유지함. 기존 게임 게시 대상과 저장 데이터는 보존함.

## 작업 재개 지점

독립 바이브 전환은 진행 중이며 아직 자동개발·런타임·게시 검증 완료가 아님.

- 웹 쪽 인계 기록: https://github.com/hans1177/jaewoon-games/pull/9413
- 로블 작업 브랜치: `work/independent-vibe`
- 이 브랜치에는 기존 바이브 import 의존성 85개와 로블 전용 정책·큐 경로 검증을 준비함.
- 중앙문서 정책 약 1.3MB에서 714KB로 1차 축소. 완전한 최소 정책 전환은 미완료.
- 집중 3개 Rojo 7.7.0 원시 빌드는 성공. 실제 게임 플레이·모바일·저장/재접속·게시 증거는 아직 없음.
- 정책 해석기 회귀 14개는 통과. 헌법 검사는 아직 미이전 모듈(외부 AI 증류·보안 학습·출처 원장 및 vibe-art-pipeline.js)을 요구하여 실패함.
- `.github/workflows/`의 기존 워크플로 3개는 검증용 스냅샷이며 필요한 도구·자산·조직 실행기·게시 키와 자체 상태 브랜치 이전 전까지 main에 활성화하면 안 됨.
- 원본의 큐·예약·성공 증거를 새 조직의 실행 성공으로 복제하지 말 것.
- 다음 작업: 위 누락 모듈과 자산/라이선스를 이전하고 헌법 검사 → 자체 빈 큐·런타임·학습 상태 초기화 → 독립 실행·게시 검증 → 실제 main 전환.
